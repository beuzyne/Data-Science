# Employee Salary & Tax Analysis with Pandas

A practical data science project focusing on data manipulation, financial analysis, and visualization using Python and Pandas.

## 📊 Project Overview
This project simulates real-world internal HR operations for a German company. It automates financial metrics calculations for Data Science team roles based on regional regulations.

## 🛠️ Tech Stack & Skills Demonstrated
* **Python**: Core programming logic
* **Pandas**: DataFrame creation, column mutation, and data filtering
* **Matplotlib**: Data visualization and custom color plotting

## 🔍 Core Features
1. **Automated Calculations**: Calculates a 40% income tax deduction and 10% annual bonuses instantly.
2. **Data Filtering**: Easily filters employees with a gross salary under €5,000.
3. **Data Visualization**: Generates custom purple bar charts for management reports.
